# 4KHD 1.9.1

本版本新增两个在线视频模块，并抽出共用的视频列表状态、播放窗口与下载入口。

## 新增

- `QuanjiGallery`：侧边栏分类入口、列表/瀑布流双布局、站点分页与搜索。
- `PornyGallery`：侧边栏分类入口、列表/瀑布流双布局、站点分页与搜索。
- 两个模块均声明 `showsDetailPane: false`，不使用右侧详情栏、胶片条和沉浸模式。双击卡片、回车或右键「播放」解析公开页 HLS 后打开独立 `AVPlayerView` 窗口；右键「下载视频」进入共享下载队列并保存为 MP4。
- 共享 `OnlineVideoGalleryStore`、`OnlineVideoFeedViewController` 与 `OnlineVideoDetailInteractionController`；播放器与 MP4 封装复用现有 App 层实现。
- 在线收藏对这两类来源使用 `playsFromFeed`：双击播放，右键提供「播放」「下载视频」，不打开详情栏。
- 设置中的列表/网格切换、侧边栏模块开关和收藏 JSON 备份覆盖这两个来源。

## 改进

- `WorkspaceModulePresentationProfile` 增加 `showsDetailPane`；无详情栏的模块不展示详情、沉浸和重置缩放，进入模块时收起详情栏。
- `PornyGallery` 列表同时收录 `/video/view/{id}` 与 `/video/viewhd/{id}`。`viewhd` 公开页若只有共享非条目清单，播放/下载改解析同一 id 的 `/video/view/{id}`。
- HLS 在每次播放或下载时现解析，不缓存会过期的查询签名。

## 稳定性与安全

- HTML 与媒体继续使用 HTTPS exact/subdomain 或 exact-host allowlist，不使用 `host.contains`。
- 公开 HTML 没有可播 `data-src`、或清单不在媒体 allowlist 时报告不可播放。不伪造 Cookie、不调用登录接口、不绕过站点验证。
- 列表、搜索和解析结果仍按请求时的 section/query 回写。

## 已知边界

- 顶部系统工具栏的 scroll-edge 半透明背景在部分三栏/详情栏状态下仍可能异常；内容继续穿过系统工具栏下方是预期行为。
- 视频播放入口会校验受信任 URL，但 AVFoundation 自行发起的后续 HLS 子请求不经过应用的逐请求门禁；视频下载链已执行逐请求校验。
