# 4KHD 1.9.2

本版本新增糖心Vlog 视频模块，并把各模块列表刷新改为系统下拉刷新。

## 新增

- `TangxinGallery`：侧边栏固定最近更新、分类目录、作者目录。标签和作者名称运行时从 `/tag/`、`/a/` 解析，不写入仓库枚举。
- 分类/作者目录使用固定宽高的标签格，长标题换行。单击目录卡片进入子信息流；视频卡片双击、回车或右键解析公开观看页 HLS 后播放。
- 模块声明 `showsDetailPane: false`。媒体 CDN 要求站点 Referer：播放走本机 `http://127.0.0.1` 代理，代理拉取密钥并解密 AES-128 MPEG-TS，清单去掉 `EXT-X-KEY`。保存 MP4 复用现有无损封装，不经过 Knit Cloudflare 验证。
- 收藏对糖心来源使用 `playsFromFeed`：双击播放，右键提供「播放」「下载视频」，不打开详情栏。
- 列表与网格接入 `NSRefreshController` 下拉刷新（`WorkspacePullToRefresh` 运行时挂接）。工具栏原刷新位置改为当前位置标题，显示模块名或当前分类/标签/文件夹。`⌘R` 与菜单「刷新」仍可用。

## 改进

- 视频播放窗口在解析 HLS 前提前打开并显示加载指示；解析失败在同一窗口提示。
- 糖心目录页隐藏列数调节；目录搜索对标签格做本地实时筛选。搜索结果走公开 `/rss.xml`，上限 200。
- 侧边栏「在线收藏」更名为「我的收藏」。Wallhaven 分组与唯一入口使用站点原名；已保存的 `group:在线壁纸` 展开状态迁移为 `group:Wallhaven`。
- 设置中的列表/网格切换、侧边栏模块开关和收藏 JSON 备份覆盖糖心来源。

## 稳定性与安全

- 糖心 HTML 仅允许 HTTPS exact/subdomain `tangxinvlog.app`；媒体仅允许 exact `t.5gcdn.xyz`。观看页只接受当前路径 id 的 `m3u8`，不取相关条目地址。
- 下拉刷新在编译期不依赖 macOS 27 SDK 类型；旧系统 no-op。胶片条、Inspector、下载窗口和侧边栏不加下拉刷新。
- 列表、搜索、详情解析和收藏详情仍按请求时的 section/query 回写。

## 已知边界

- 顶部系统工具栏的 scroll-edge 半透明背景在部分三栏/详情栏状态下仍可能异常；内容继续穿过系统工具栏下方是预期行为。
- 视频播放入口会校验受信任 URL，但 AVFoundation 自行发起的后续 HLS 子请求不经过应用的逐请求门禁；视频下载链已执行逐请求校验。
- `NSRefreshController` 仅在 macOS 27 及以上生效。
