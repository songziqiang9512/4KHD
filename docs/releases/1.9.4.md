# 4KHD 1.9.4

共用视频窗口关闭系统 `AVPlayerView` 浮层，改为底部 AppKit 控制条。

## 改进

- `AVPlayerView.controlsStyle = .none`。底栏宽度跟随按钮总宽，固定大小，窗口底部居中。
- 快退与快进分档：5 秒、10 秒、30 秒、1 分钟、5 分钟。播放/暂停在正中；音量与倍速为按钮，弹出竖向滑块（始终在按钮上方）。倍速滑块吸附 0.5 / 0.75 / 1 / 1.25 / 1.5 / 2。
- 点击画面空白处隐藏或显示底栏。空格播放/暂停，左右方向键按 10 秒跳转。
- 音量与倍速写入 `UserDefaults`，换片时恢复。
- `seek` 完成前不把周期性时间观察写回进度条，避免快进时回弹。

## 稳定性

- 换片或关窗取消 time observer、item KVO 和本机 HLS 代理 session。
- 画面右键仍提供「保存视频为 MP4…」和「拷贝影片源 URL」。

## 已知边界

- 顶部系统工具栏的 scroll-edge 半透明背景在部分三栏/详情栏状态下仍可能异常；内容继续穿过系统工具栏下方是预期行为。
- 视频播放入口会校验受信任 URL，但 AVFoundation 自行发起的后续 HLS 子请求不经过应用的逐请求门禁；视频下载链已执行逐请求校验。
