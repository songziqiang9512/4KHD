# 4KHD 1.9.3

本版本新增 TaiAV 视频模块，并调整侧边栏分组与网格卡片交互。

## 新增

- `TaiavGallery`：侧边栏固定最近更新与原站 4 个分类。只使用 `/cn`。卡片为 `movie-card` + `/cn/movie/{24hex}`，跳过 `/file/` 广告。首页 `/cn` 无分页；分类页下一页来自 `&raquo;`。搜索 `/cn/search?q=`，查询串百分号编码。
- 模块声明 `showsDetailPane: false`。双击、回车或右键「播放」请求公开 `GET /api/getmovie?type=1280&id=`，只取 JSON `m3u8`。相对路径拼到媒体 CDN。签名 query 每次播放/下载现请求。AES-128 MPEG-TS VOD 保存 MP4 复用现有无损封装，不经过 Knit Cloudflare 验证。媒体 CDN 需要站点 Referer 时走本机 `http://127.0.0.1` 代理。
- 不调用购买、积分、登录、签到或站点下载接口。
- 收藏对 TaiAV 使用 `playsFromFeed`：双击播放，右键提供「播放」「下载视频」，不打开详情栏。
- 设置中的列表/网格切换、侧边栏模块开关和收藏 JSON 备份覆盖 TaiAV。
- 站点分页和入口实测快照见 `docs/taiav-site-protocol-2026-09-03.md`。

## 改进

- 侧边栏站点分组标题 15pt semibold。点击标题展开或收起；收起前若当前选择在该分组内则先取消选择，避免大纲视图自动重新展开。分组行隐藏左侧系统 disclosure，改为行内右侧 chevron。图片源与视频源使用不同 SF Symbol。
- 网格卡片悬停只描边，去掉悬停和按下缩放。瀑布流不再为缩放预留额外间距。
- 视频网格/列表 cell 复用时清空旧封面；封面 URL 变化且缓存未命中时先显示占位，避免分类切换或加载更多时串图。

## 稳定性与安全

- TaiAV HTML 仅允许 HTTPS exact/subdomain `taiav.com`；API 仅 `/api/getmovie`；媒体仅 exact `img.storyofthepast.xyz` 与 exact/subdomain `snmovie.com`。清单路径必须含当前影片 id。
- 列表、搜索和解析结果仍按请求时的 section/query 回写。

## 已知边界

- 顶部系统工具栏的 scroll-edge 半透明背景在部分三栏/详情栏状态下仍可能异常；内容继续穿过系统工具栏下方是预期行为。
- 视频播放入口会校验受信任 URL，但 AVFoundation 自行发起的后续 HLS 子请求不经过应用的逐请求门禁；视频下载链已执行逐请求校验。
