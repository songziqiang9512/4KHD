# 4KHD 1.9.0

本版本新增“每日大赛”在线图库模块，并让爱妹子与每日大赛的 AES-128 HLS 可以保存为 MP4。

## 新增

- 侧边栏增加「每日大赛」：最近更新加原站 20 个分类；列表/瀑布流双布局，搜索与分类使用站点真实分页。
- 详情支持缩放、上下张、胶片条和沉浸模式；图片来自详情页 `data-xkrkllgl`，密文 CDN 按原站算法解密后显示、保存和整图集下载。
- 最后一张继续向后翻页显示相邻推荐；邻篇封面优先使用档案页横幅，否则取第一张解密后的详情图。
- 解析到 HLS 后可用独立原生窗口播放、拷贝影片源 URL，并保存为 MP4。
- 收藏、整图集下载、Inspector 已接入统一工作区；设置中的侧边栏开关与收藏备份覆盖每日大赛记录。

## 改进

- 爱妹子与每日大赛的 MPEG-TS VOD 若使用 AES-128，保存 MP4 时先下载密钥、按 KEY 行 IV 解密 TS，再无损封装。
- 网格卡片标题始终显示；切换分类时先恢复该分类的内存列表，封面不先清空再淡入。
- 搜索结果封面与详情共用同一解密加载管线；搜索路径编码与站点一致。
- 收藏详情胶片条按分页图片导航显示，不再因为 Inspector metadata 已存在而隐藏。

## 稳定性与安全

- 每日大赛 HTML 仅允许 HTTPS exact/subdomain `mrds66.com`；媒体仅允许 `pic.sbhioa.cn`、`hls.piotrt.cn`、`ts.syjiaotong.mobi`、`tx.doudou520.online`、`ts.zhixunkeji.xyz`。
- HLS 密钥或分片不在 allowlist 时报告来源不受信任，不再误报「影片清单格式无法识别」。
- 在线分页、搜索、详情解析和收藏详情继续按请求身份隔离旧异步结果；失败页可重试且不会提前进入推荐。

## 已知边界

- 顶部系统工具栏的 scroll-edge 半透明背景在部分三栏/详情栏状态下仍可能异常；内容继续穿过系统工具栏下方是预期行为。
- 视频播放入口会校验受信任 URL，但 AVFoundation 自行发起的后续 HLS 子请求不经过应用的逐请求门禁；视频下载链已执行逐请求校验。
